# DEC-009 — Fiscalidad al reemplazar Alegra

Estado: **descartada por decisión expresa del dueño el 18-09-2026**.

## Decisión vigente

- La confirmación de un contador y un procedimiento fiscal con Alegra no son requisitos para operar ni para lanzar esta versión.
- Caja emite comprobantes internos. La emisión o integración fiscal/electrónica externa queda fuera del alcance de esta versión.
- Los impuestos de producto continúan siendo opcionales: un campo vacío permanece «Sin impuesto asignado», no calcula impuesto y no equivale a tasa 0 % ni a exención.
- No se debe reintroducir DEC-009 ni GO-03 como puerta de lanzamiento sin una instrucción posterior y expresa del dueño.

Este registro sustituye la propuesta transitoria anterior. No afirma obligaciones tributarias ni modifica Alegra.
