# GO-02 — validación representativa de inventario y costos

Fecha: 18-09-2026. Validó: dueño de Nativos.

El dueño confirmó que realizó en el piloto una prueba con un producto y un insumo y que el resultado fue correcto. También confirmó que esta prueba representativa es suficiente para cerrar GO-02 y que no se requiere cargar el inventario completo de Milán y Centro antes de operar el piloto.

## Alcance aprobado

- Queda validado el flujo de inventario y costos para el piloto.
- El catálogo, las cantidades y los costos restantes pueden cargarse progresivamente con datos revisados.
- Un costo desconocido permanece como desconocido; no se convierte en cero.
- No se deben inventar cantidades, costos ni conversiones para completar la carga.

Esta aprobación cambia el criterio operativo de GO-02; no afirma que ya exista un conteo físico completo de ambos locales.
