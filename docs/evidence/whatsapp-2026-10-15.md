# Reportes del dueño por WhatsApp — 15-10-2026

## Alcance y autorización

El usuario solicita implementar con SDD y desplegar en el entorno de pruebas existente de Railway. Sólo dueño personal, emisor Business del negocio; cierre más consolidado de Centro/Milán después de cada cierre sincronizado, mínimos consolidados a las 08:00 Colombia. No hay encargados ni cuenta Meta configurada. El envío real permanece desactivado; no se contratan servicios ni se envían mensajes reales.

Trazabilidad: [spec 009](../../specs/009-whatsapp/spec.md), [plan](../../specs/009-whatsapp/plan.md), [tareas](../../specs/009-whatsapp/tasks.md), [contrato v2](../../contracts/notifications-v2.md), DEC-010 y [guía operativa](../operations/whatsapp.md).

## Resultado implementado

Instantáneas inmutables por cierre con comprobante compartido, ventas de productos netas separadas del recaudo, propinas/domicilios netos, medios y última sincronización de cada sucursal. Primer cierre puede ser parcial; segundo cierre genera otra instantánea; reintentar no duplica. Mínimos consolidados con corte durable incluso vacío y recuperación durante el mismo día. Muestra manual siempre preview, independiente del corte automático.

Modos legacy/preview/live congelados: un registro viejo o de prueba nunca pasa automáticamente a envío real. Adaptador Cloud API fijo a Meta, configuración sólo desde entorno, aceptación distinta de entrega, callback HMAC de bytes originales, concurrencia por fila, timeout/5xx/interrupción inciertos, backoff limitado y verificación de destinatario/alcance antes del envío. Intentos/callbacks y cortes incluidos en respaldo y restauración aislada.

Pantalla WhatsApp para dueño: estado de conexión, lista paginada, informe por enlace después de login, vista previa, simulación sin alterar estado de entrega y Excel completo. API comprueba todas las sucursales del documento. Tablas de medios desplazables en móvil; ambos temas y navegación de teclado.
